# Simple machine learning projects

Two small regression projects from my early machine learning learning, each in its own folder.

| Project | What it does | Test R2 |
|---|---|---|
| [Car-Sales-Analysis](Car-Sales-Analysis) | Predicts car prices from engine and body specs with four regressors | 0.85 (linear) to 0.94 (random forest) |
| [Simple-Salary-predictions](Simple-Salary-predictions) | Linear regression of salary on years of experience (30 rows) | 0.90 |

The car project is also published on its own as `car-sale-analysis`, with a fuller README.

Both are tiny datasets with a single train/test split, so treat the scores as a demonstration of the workflow.
