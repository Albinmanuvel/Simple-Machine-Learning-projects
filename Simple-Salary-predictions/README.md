# Salary prediction

Linear regression of salary on years of experience (`Salary_Data.csv`, 30 rows). The notebook `salary_pred.ipynb` explores the data with Plotly, fits the model (80/20 split, `random_state=42`) and reports error metrics.

Test R2 = 0.90. With 30 rows this is a demonstration, not a reliable salary model.

Run: `pip install pandas numpy plotly scikit-learn` and open the notebook.
